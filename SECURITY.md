# Security policy

This repository is a portfolio case study. It contains documentation,
screenshots taken with made-up data and a selection of platform modules. Nothing in it is deployed from here,
and it holds no credentials or configuration for any environment.

The snapshot is produced by a publishing gate: an allowlist of paths,
redaction of infrastructure details, and a scanner that blocks the
publication on secrets, personal data or infrastructure identifiers.

## Reporting

If you believe something in this repository exposes sensitive information,
or you have found an issue in the live product (app.reconnectia.es) or its
marketing site (reconnectia.es), please report it privately instead of
opening a public issue. Reach me through
[danielbrosed.com](https://danielbrosed.com).

Valid reports are acknowledged and credited.
